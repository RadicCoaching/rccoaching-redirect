# rccoaching.dk → radichcoaching.dk

(repo `rc-hjemmeside-public`). Alle stier (også ukendte, via 404.html) sendes videre med stien bevaret. Bruger GitHub Pages
i stedet for Simplys URL-viderestilling, fordi den kun dækker http:// og ville give gamle https://rccoaching.dk-links en
sikkerhedsadvarsel.
